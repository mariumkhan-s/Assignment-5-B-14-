Ques Answers:
1) JSX is a syntax that lets us write HTML-like code inside JavaScript. 
2) Props are data passed from a parent component to a child component whereas State is data managed inside a component that can change over time.
3) The useState hook is used to create and manage changing data in a React component. 
4) The useEffect hook runs code when something happens in a component,I used it to load the JSON data when the page started.
5) Each item needs a unique key so React can identify the items correctly.It helps React update the list efficiently when the data changes.
6) Conditional rendering means showing different content depending on a condition.
7) A parent passes data to a child using props.A child can send information back to the parent by calling a function that the parent passes to it through props.
